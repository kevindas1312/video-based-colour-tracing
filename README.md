# 🎨 Video-Based Colour Tracing App

A lightweight, real-time computer vision application that turns your PC webcam into a dynamic color-tracking tool! Built with Python, OpenCV, and NumPy.

> **Note:** For optimal tracking accuracy, this application works best in well-lit environments.

---

## ✨ Features
* **Real-Time Tracking:** Instantly isolates and follows target colors from your webcam feed.
* **Lightweight & Fast:** Leverages OpenCV and NumPy for efficient frame processing.
* **Scalable Foundation:** Easily extensible for automation, robotics, or interactive games.

---

## 🚀 Getting Started

### Prerequisites
Make sure you have [Python](https://www.python.org/) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kevindas1312/video-based-colour-tracing.git
   cd video-based-colour-tracing
2. **Install the dependencies**
   You will need opencv-python for handling webcam video streams and numpy for matrix/array operations. Run the following command in your terminal:
   ```bash
   pip install opencv-python numpy
3. **Run main application script**
   ```bash
   python main.py
